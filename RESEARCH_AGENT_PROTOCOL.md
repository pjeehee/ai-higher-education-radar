# Research Agent Protocol

For each queue task:
1. Search only the specified source families first.
2. Prefer official primary pages and original reports/frameworks.
3. Capture candidate URL, exact title, institution, publication/update date, and source type.
4. Extract only claims directly supported by the primary source.
5. Do not infer missing dates, implementation status, scope, outcomes, or institutional policy.
6. Check whether the candidate duplicates an existing Evidence record.
7. Route every candidate to verification; never publish directly.
8. Preserve credible contradictory evidence.
9. After verification, recompute Gap Matrix and Signal Score.
10. Stop expanding dense areas while P1 corpus gaps remain.
