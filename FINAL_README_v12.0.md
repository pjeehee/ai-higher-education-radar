## Stable architecture
Evidence -> Verification -> Topic/Institution mapping -> Implementation maturity -> Cross-source corroboration -> Signal -> Outcome/Value -> Executive brief -> Audit trace.

## Non-negotiable rules
1. Selection/funding is not implementation.
2. Plans are not operation.
3. Participation/satisfaction are not learning outcomes.
4. Institution-specific evidence is required for implementation promotion.
5. Preserve program provenance.
6. Strong signals require independent source-family corroboration.
7. Adoption metrics are not evidence of effectiveness.
8. Every material intelligence change must be traceable to evidence.

## Product boundary
This package is a static research/UI release candidate. Live crawling, database persistence, authentication, scheduler, alerts, and production analytics require the backend handoff already documented in the package.
